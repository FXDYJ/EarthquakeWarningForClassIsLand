# TREM 台站观测

## Direction contract

本功能在现有预警中心看板中增加独立观测层，并提供平时可打开的原生观测窗口。沿用深色表面、中文系统字体、矩形分区和原生按钮；彩色方形台站与圆形震中/本地标记区分。观测窗口左地图右读数，顶部连接/时标，底部持续显示覆盖范围、标度与署名。全屏仅增加地图外的观测状态及入口，不遮挡地图和避险动作。

观测值与中国本地预估烈度分开，数据未知时清空数值。验收要求包括实时接收、过期/断线/关闭、目录失败、悬停读数失效、不同窗口尺寸和预警入口隔离；不把模拟截图、短时联网或核验测试当成现场避险精度证明。

## 使用

提醒设置 → 台站观测（TREM）→ 查看台站地图与观测值。默认启用，随“启用监测与告警”总开关暂停；独立开关只控制台站观测。预警窗口地图下方也提供“台站”入口。关闭观测窗口不停止后台接收；停用或宿主退出取消共享连接。

站点以方形显示，可缩放、拖动，悬停查看设备、观测震度、PGA 与时标。“全部台站”恢复台站覆盖视图。右侧按设备编号稳定排列，位置包含设备楼层；PGA 为来源提供的 0.5 秒三轴矢量和峰值，单位 gal（cm/s²），不是原始波形。观测震度使用 TREM 的原始 0–7 标度及弱/强细分，不转换成中国烈度，不用 PGA 反推震级或烈度。

观测窗口没有警报音、音量接管或外部命令。它不自动弹出，也不参与事件核验。TREM 台网主要覆盖台湾地区，不代表大陆本地已有观测。演练预警不叠加无关实时台站，独立观测窗口仍可手动查看真实数据。测试用模拟台站状态须携带 Simulated 标记并显示徽标。

## 接口与数据质量

- [台站目录](https://exptech.dev/en/docs/api/stream/station/)：`https://static.core-tnn1.exptech.dev/resource/station`，东京节点为备用。响应虽标记 application/json，正文是 CSV。启动获取，正常每天更新，失败按分钟重试；失败后保留内存中的上次有效坐标并显示目录错误，不将目录当作在线状态。
- [实时观测](https://exptech.dev/en/docs/api/stream/rts/)：`https://api.lb.exptech.dev/api/v1/trem/sse/rts?mode=live`。一个共享 SSE 连接接收 2 Hz 完整快照，消息为 Base64 包裹的 Gzip JSON。断线在 3–30 秒退避后轮换官方入口重连，不为每个窗口另开连接。
- 以快照完整替换读数，缺席台站立即变未知；`i=-3` 为无信号，不伪装成震度零；缺失 PGA 为未知，实际测得的 0 则保留。
- 当前可用要求连接仍有效且快照与本机时间差不超过 ±5 秒。明显过期/超前报文不进入当前读数，倒序/重复报文不覆盖新帧。时标有误时提示检查系统时间，不声称负时间差是低延迟证明。
- SSE 单行/事件、目录、解压大小和记录数量有上限；字段、坐标、设备编号和数值范围检查失败时保留错误状态并重试，不能把异常响应作为有效零值。

## 数据使用范围

来源为 ExpTech 自建 TREM-net 的自动观测，非官方地震信息；按其[数据使用说明](https://exptech.dev/en/docs/api/start/license/)署名、仅限非商业用途，以中央气象署发布为准。该限制同样适用于使用本功能的部署；插件代码许可证不等于数据商业授权。

本次没有取得大陆官方密集预警台站、EarthScope 或 NIED 的授权实时数据，也没有接入原始波形。后续接入须分别核实权限、地理覆盖、仪器响应和数据时效，不能将台站数量直接当成独立核验票。
