# 全屏预警中心看板方向

- 模式：Operate，原生 Windows / Avalonia，代码主导，在现有深色和三档警戒色中扩展。
- 用户确认：教室避险优先；整体采用预警中心看板，不需追溯特定 RTEM 项目。
- 首屏：左本地倒计时/预估烈度，中央独立大地图，右侧常显接收证据，底部三步动作。地图不遮罩。
- 风格：保留现有 Microsoft YaHei UI / Bahnschrift、蓝/琥珀/红和直线面板。层级与地图密度提供科技感；不添加频闪、装饰仪表或虚构数据。
- 状态交互：D 展开报文详情；新进入分歧/过期/范围外自动展开。预测暂停不保留貌似有效的数字；预计到达后仍提示防护。M 静音，Esc 关闭。
- 约束：后端核验/动作/计算/女声素材不改；接口不是台站；波前非实测；保留演练身份。
- 验证：1920×1080、1280×720、1280×960、2560×1080；有感/强烈/微弱/到达/末秒/分歧/过期/未知/长地名/展开详情。截图是原生无头渲染，不是教室实机证明。
