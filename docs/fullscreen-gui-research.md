# 地震预警全屏界面调研与改版依据

调研日期：2026-11-19。范围为公开可访问的官方产品页、原始项目资料、使用手册和界面示例。无法穷尽全球所有终端；本报告覆盖 14 个代表性产品/渠道分组。未把宣传语当成已测得的时效或准确性。用户最终明确：不需追溯某个 RTEM 项目，以「地震预警中心看板」为整体布局，同时保留教室远距离阅读优先。

## 代表性界面对比

| 产品或渠道 | 已取得的证据 | 界面和信息组织的特点 | 本插件的取舍 |
| --- | --- | --- | --- |
| 中国手机预警 | 公众使用指引中的手机示意 | 本地影响、预计时间和震情有明确标签 | 保留中文烈度含义及震级/烈度区别；不将日本震度颜色直接套用 |
| 中国专用预警终端 | 公众指引中的终端图 | 大号倒计时位于视觉中心，避险提示与来源明确 | 大字倒计时和本地烈度进入固定左栏；不照搬天气、装饰圆环等非震时信息 |
| 中国电视预警 | 公众指引中的电视图 | 大色块突出告警与行动，参数排成短行 | 保留警戒色及清楚动作；不以大面积半透明弹层遮住地图 |
| CWA 地震速報接收软件 | 官方手册第18–19页截图 | 地图居中，所在地预测震度与到达秒数有独立区域，状态与图例分区 | 借鉴稳定地图、当地影响、状态栏；不复制其日本/台湾震度标度 |
| TREM-Lite | 项目 README、公开 Web 版实际界面 | 专业监测看板，以地理视图组织即时报文、测站及震度 | 借鉴地图主导和常显侧栏；本插件没有实测站网，不画虚构站点或观测热力区 |
| JQuake | 官方产品页与预测/观测功能图 | 分区着色、震中、波前与实测点叠加，适合监测人员 | 地图与波前可借鉴；预测和实测必须分开，本插件只标传播示意 |
| NERV 防灾 | 官方说明与实时活动示例 | 当前地点的预测影响与到达倒计时相邻，紧急信息少而集中 | 学习两项本地信息紧邻；不复制其品牌符号与监测授权含义 |
| Android 地震提醒 | Google 官方三种提醒示例 | 轻重分层；强提醒以明确行动词和图形引导为主 | 保留按本地影响区分颜色，底部常驻三步动作；不把手机纵向页面拉伸成教室大屏 |
| MyShake | Berkeley 官方页面与提醒示意 | 强调预计摇晃及 Drop/Cover/Hold On，事件查看和公众报告是另一层功能 | 强化当下动作；不把公众感觉报告当成官方核验票 |
| P2P 地震情報 | 官方产品说明 | 官方地震信息与用户「感觉到摇晃」的共享信息属于不同来源 | 右栏明确接收路径和发布机构；接口数量不等同独立台站 |
| SignalNow X | 官方功能说明 | 计算指定地点的预测震度和剩余秒数 | 不以震中震级替代本地影响；当地指标保持高权重 |
| Yurekuru Call / 光BOX | 厂商使用说明 | 解释某个地点将有多强震动、还有多少秒，并提供地图与详情 | 学习两项本地信息的直白标签；演练和真实数据明确分开 |
| SASSLA | 官方页面与警报呈现说明 | 强警报强调红色告警和剩余时间 | 学习紧迫状态的高对比；不引入频闪，也不移植其当地预警信号与时效宣称 |
| SkyAlert | 官方 FAQ / 桌面接收器说明 | 强调当地震动强度，并说明其与震级不同 | 不把 M 值作为本地破坏程度，不把预测值包装成实测 |

上述中国三种渠道来自同一份公众指引，属于三个呈现样本，并非三个独立产品。TREM 实际 Web 界面通过静音的无头浏览器进入，但当前连接异常，地图未完整加载；因此只参考其看板结构与项目说明，不把该截图视为完整地震演示。CWA 使用官方 PDF；NERV/Google/中国终端/JQuake使用官方示例图。其余为公开功能或使用说明，未实际安装全部客户端，也未观察真实地震触发过程。

## 核心结论

1. **看板布局与信息优先级可以同时成立。** 地图放中央，左栏常驻本地影响和到达时间，右栏常驻核验证据；学生先读左栏和底部动作，老师可查看中央地理关系与右栏来源。
2. **震级、本地预估烈度、到达时间是三种不同量。** 大字必须标清「本地预估烈度」；M 值保留但降低视觉权重。日本震度、台湾震度和中国烈度的颜色/等级不能当成同一标度。
3. **到达不等于安全。** 归零切换为「预计震动已到达」和继续防护；不能从倒计时推断现场已经开始或结束摇晃。
4. **先行动，不等数字归零。** 强提醒持续显示「立即就近避险」「不要等待倒计时结束」，底部列出伏地、遮挡、抓牢。教室里震后按老师指挥有序撤离。
5. **核验信息不能藏掉，也不能占据地图。** 右栏始终可见接口名、参数和状态，详细地点、报次、时标可展开；出现分歧、过期等情况自动展开详情并暂停预测读数与预测波圈，仅保留待核验参考位置。
6. **未知值不是零。** 模型范围外、证据不足、撤销或参数分歧显示破折号及状态，不渲染确定的本地烈度和倒计时。
7. **界面不能伪造数据能力。** 不显示虚构可信度百分比、台站点、PGA、观测热力图、海啸状态或预计结束时间。现有 P/S 圆环继续明确标注传播示意。
8. **紧迫感由信息层级产生。** 保留蓝/琥珀/红和高对比状态，不依赖频闪、警戒条纹、随机图形或装饰性仪表。

这些是基于产品资料和当前应用约束的设计推论，并非已证明提升了真实避险成功率。

## 本次实现

- 1600×900 基准的原生 Avalonia 三列看板：342 单位左栏、伸展地图、282 单位证据栏；下方为固定动作带和状态栏。
- 画布按实际窗口纵横比扩展，16:9、4:3 和超宽屏都利用可用空间；文字与交互共同等比缩放。
- 地图按钮、图例和署名都在地图外，不覆盖行政地名。长震中地名换行/省略，悬停可查看完整文本。
- 保留 M 静音、Esc 关闭，新增 D 展开/收起报文详情；演练身份持续可见。
- 所有可靠性规则、地震计算、女声素材、音频接管与外部动作条件维持现有后端约束；此次主要改变全屏呈现和状态说明。
