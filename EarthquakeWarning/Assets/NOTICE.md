Offline map data from Natural Earth, public domain.

Countdown WAV assets are newly generated speech from the installed Windows Microsoft Huihui voice (rate 5 for numbers, rate 2 for generic messages). No phone-vendor recordings were copied. Single/double-beep waveforms are generated by this plugin. Number recordings are played in a bounded slot and the alert style is selected from estimated local intensity.

The map displays geographic outlines and estimated wave propagation. It contains no real-time station observations.
