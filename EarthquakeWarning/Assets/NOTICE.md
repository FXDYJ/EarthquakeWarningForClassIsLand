Offline map data from Natural Earth, public domain.

Countdown WAV assets are pre-generated Microsoft Yunxi neural speech (zh-CN-YunxiNeural), created at build time through edge-tts. No vendor alarm recordings were copied. The runtime plugin makes no online speech requests. It plays natural-pitch clips; counts 11–60 use two-second slots and the final ten use one-second slots. Warning sweeps and zero/single/double beep patterns are generated by this plugin.

- Build-time tooling: https://github.com/rany2/edge-tts
- Generator: tools/generate_countdown.py

The map displays geographic outlines and estimated wave propagation. It contains no real-time station observations.

The conservative mainland model coverage gate is derived from Natural Earth ne_110m_admin_0_countries, public domain. It is a coarse computation gate, not an administrative boundary service.
