# 🌍 ClassIsland 地震预警插件

![Banner](https://raw.githubusercontent.com/denglihong2007/MyPhotoBed/refs/heads/master/e695f20f-2474-41ce-be05-4957873ee48b.png)

一个为 **ClassIsland** 量身定制的实时地震预警 (EEW) 扩展插件。

## 🚀 快速上手

### 1. 安装插件
* 下载最新的插件发行包。

### 2. 关键设置（必读！）
> [!CAUTION]
> **安装后，插件默认可能不会立即生效。为了确保您能收到预警，请务必执行以下操作：**
> 
> 1. 打开 ClassIsland **设置**。
> 2. 导航至 **[提醒]** 设置页。
> 3. 在 **[提醒提供方]** 栏目中选择 **[地震预警]** ，配置您的**地理位置信息**、**预警阈值**以及**通知策略**。
> 4. 建议点击“预警演练”以确保弹窗正常工作。

## ✨ 功能特性

* **多接口监测**：接入 MIUI、CENC 直连，以及 Wolfx 的中国台网、四川、福建、重庆、日本 EEW 与中日地震目录，支持实时推送和 HTTP 轮询。
* **综合核验**：默认先在 CI 显示待核验信息。必须有 CENC 直连正式测定，与另一接收路径的预警严格吻合，才触发全屏、语音和外部命令。优先减少误报，可能牺牲全部提前量。Wolfx HTTP 与推送合并计数。
* **全屏震情**：在 CI 所在屏幕显示无边框窗口，包含震级、本地预估烈度、预计到达时间、离线底图、估算波前和逐接口对比，可静音或按 Esc 关闭。
* **分工语音**：先解释地震及避险方式，再播到达秒数。使用不同中文音色时支持详情与倒计时并行，详情自动降低音量，最后十秒暂停详情。默认固定离线数字音频可与解说并行；关闭固定报数时，相同合成音色自动错峰。支持开关音量增强。
* **高度自定义**：支持自定义本地烈度阈值、地理位置等。

## ⚠️ 免责声明

* **非预测工具**：本插件仅分发地震预警信息，并非地震预测。

## 综合核验与演练

- 关联条件为发震时刻相差不超过 15 秒、震中相距不超过 60 km。相同接口上的不同事件 ID 不会合并。
- 升级要求所有有效报文发震时间差不超过 5 秒、震中相距不超过 20 km、震级差不超过 0.3，双方有深度时深度差不超过 15 km。出现分歧暂停升级与语音，界面显示待复核。
- 超过 5 分钟、未来超过 10 秒、参数非法、演练标记的网络报文不会进入真实预警。撤销报终止对应预警，旧报次不会覆盖新报次。
- 综合模式必须有 `CENC/cenc-bulletin` 直连正式测定，另有不同接收路径的有效预警报文。正式测定深度必须已知且不超过 30 km；单纯多个预警转发或目录不能升级。单来源模式提供 CI 待核验提示与数据查看，不能单独触发全屏、语音或 CMD。
- 预警演练会先模拟单源，再模拟两接口吻合。演练与真实数据隔离，演练从不执行 CMD，真实已核验预警会优先显示。
- 在 Windows 安装两个中文语音后，可在设置里分别选信息音色和倒计时音色。默认数字报数使用随插件提供的固定离线音频，配合偏右声像和短促音色，可与解说分工并行。关闭固定音频、且两路合成音色相同时，自动错峰播报。
- 地图中的波前为估算示意，烈度与到达时间为本地模型估算。本地模型仅在保守限定范围内工作：Natural Earth 中国大陆粗略覆盖区内的震中与用户位置、震级 4.0–8.5、已知深度 0–30 km（不含未知）、震中距不超过 500 km。境外、深源、未知深度和范围外不输出伪精确数值，也不执行强预警动作。

接口状态里的“可达”表示请求和解析成功，最新事件的发震时间单独显示。近期没有地震时，返回较旧的快照属于常见情况。

构建 `dotnet build EarthquakeWarning/EarthquakeWarning.csproj -c Release -p:CreateCipx=true`。

回归检查 `dotnet run --project EarthquakeWarning.Tests/EarthquakeWarning.Tests.csproj -c Release`。

离线地图使用 Natural Earth 公共领域数据，来源见 Assets/NOTICE.md。

## 地图与三类提示音

地图默认连接 OpenStreetMap 256px HTTPS 瓦片，无需密钥。只下载当前可见范围，支持拖动、滚轮/按钮缩放和恢复震中/本地视野；在线底图按比例显示行政区和街道地名。使用 Web Mercator 投影，保留署名、应用 User-Agent 与至少七天缓存。地图失败不阻塞预警，自动回退到离线国界、省界与地名。离线小比例尺显示国家，中比例尺显示省级名称，大比例尺显示城市；离线数据不包含完整县级和街道名称。设置中可关闭联网或配置兼容瓦片地址及其署名。

按本地预估烈度选择三类提示，分界为 3 和 6：

| 预估影响 | 本地预估烈度 | 界面 | 报数间提示 |
| --- | --- | --- | --- |
| 无感或微弱震感 | < 3 | 蓝色 | 无滴声 |
| 有感无破坏 | 3 至 < 6 | 琥珀色 | 单滴 |
| 有感有破坏 | ≥ 6 | 红色 | 双滴 |

这些描述表达模型估算的影响，不能保证个别建筑的实际破坏情况。节奏参考国内常见预警报数方式，数字与提示音由本项目预生成，音色并非任何手机厂商的原版录音。1–60 的数字采用 Xiaoxiao 中性女声神经语音预生成；运行时完全离线。11–60 秒每两秒报数，最后 10 秒逐秒报数，保留正常声调和停顿，不截断音节或用重采样变调。先播放短警报引导音、说明震情，再报数，最后十秒暂停详情，撤销、静音和关闭都会取消本次播报。Windows 没有中文音色时使用内置通用说明及报数，详细数据仍可在屏幕查看。

原版声音节奏说明见 https://admin.yixi.tv/h5/speech/971/ 。本地烈度一般影响说明见 https://dataportal.earthquake.cn/channel/earthScience 。

## 0.10.1 核验与音频修正

- 修正本地预估烈度的距离口径：论文中的 R 为震中距，不使用震源距替换。按汪素云分区关系（2021 年论文表 3 所列系数）计算长短轴后取方位平均；东部短轴系数为 3.071，使用 log10。这仍是模型估算，不是现场实测或统计置信下界。震级直接保留正式测定值，不用烈度反推震级。
- 参考与固定算例：<https://html.rhhz.net/dzdczz/html/66604.htm>。东部 M6、震中距 100 km 的平均估算为 4.8478355675；西部为 4.6588454689。该模型没有场地、建筑和断层走向信息；未把不同震级标度伪称为已转换的 Ms。
- 走时仅对支持范围作距离/深度双线性插值。未知深度不再默认 10 km，深源不再夹到 30 km，取消无限远距离外推。4.0–8.5、30 km 和 500 km 是插件保守门槛，不代表已证明全范围物理精度。
- 网络响应按完整批次原子提交，只接受最新修订。缺参数撤销与先到撤销保留 tombstone；未知归属的近期撤销会暂时阻止升级。相同修订改写、无法唯一归属的相邻事件阻止确认。有效票超过 30 秒未刷新即失效；切源/暂停清票但保留报次、冲突、撤销与动作去重历史。
- 真实确认预警默认暂停支持 Windows 系统媒体控制的播放器、静音其他进程的可控制音频会话，并将默认多媒体/控制台设备及 CI 会话音量调至最大。清空 CI 当前语音队列；未终止进程，也不能停止不受 Windows 混音器管理的独占/硬件音源。CI 同进程的其他插件若自行播放且不走宿主语音队列，无法保证被停止。
- 静音、撤销、关闭、停止监测或退出时恢复原系统音量和应用静音状态；先降低主音量再解除其他应用静音。被暂停的媒体不自动恢复播放，避免突然响起。演练不接管系统媒体或主音量。
- 神经数字由构建工具 `tools/generate_countdown.py` 通过 Edge TTS 预生成并保存为 WAV；该服务仅用于制作素材，不作为运行时可靠性依赖。运行时详细震情仍使用已安装的 Windows 中文音色，最后十秒只保留报数。
- 地图不再覆盖底部遮罩；图例及署名位于地图外。全屏移除语音实现说明和内部事件 ID。

构建环境：Windows 10 2004 或更新，.NET 8 SDK；插件宿主仍使用 ClassIsland PluginSdk 2.0.0.1。实际教室扬声器、多个音频设备和真实地震的到时/烈度需现场验收，回归检查不能证明零误报。

## 0.10.2 女声调整

所有内置报数及说明改为 Xiaoxiao 中性女声，以正常语速和原始音高生成，不增加播音腔或情绪效果。震情说明和备用系统报数只选择中文女声；旧配置中的男声自动回退到可用女声，没有中文女声时使用内置女声通用说明。保留开场警报与三档滴声。音色、语速、音高及生成器指纹在生成时固定，禁止复用其他音色的缓存素材。
